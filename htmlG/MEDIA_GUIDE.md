# Медиа страницы «О проекте» Gansar

Страница открывается существующим пунктом CLI `7` или напрямую как `htmlG/about.html`. Сервер, CDN, внешние шрифты и доступ к интернету для её ресурсов не нужны. Внешние Telegram-ссылки открываются по нажатию. Изображения предоставлены пользователем; Эмма Уотсон не заявляется участником или официальным представителем проекта.

## Сопоставление файлов

Редактируемая карта находится в `htmlG/media-manifest.js`, объект `window.GANSAR_ABOUT_MEDIA.slots`. Каждая запись имеет свой ключ, список `files`, тип `image` / `video` / `auto` и признак `animated`. Файлы ищутся только в `htmlG/assets/`, по порядку внутри своей записи. Отсутствующее изображение никогда не заменяется изображением другого ключа.

| Ключ | Текущий пользовательский файл | Место в композиции |
| --- | --- | --- |
| `background` | `emma-background.webp` | Неподвижный фон первой секции, отдельно от текста |
| `gallery1` | `emma-gallery-01.webp` | Рядом с описанием проекта |
| `gallery2` | `emma-gallery-02.webp` | Не показывается в основном макете; файл и запись manifest сохранены |
| `motion1` | `emma-motion-01.gif` | Не показывается в основном макете; файл и запись manifest сохранены |
| `kiss` | `Emma Watson Kiss GIF.gif` | Одна компактная GIF рядом с тремя контактами, на узком экране под ними |
| `motion2` | `emma-motion-02.gif` | Статичное фото внутри личного ответа FAQ об Эмме; видно при раскрытии вопроса |
| `portrait` | Файл сейчас отсутствует | Не используется в основном макете; запись manifest сохранена |

Ни один из исходных медиафайлов не изменён, не переименован и не продублирован. В видимой странице нет технических подписей «Фотографии», «GIF 1», «Основной портрет» или их английских аналогов.

### Причина ошибки с GIF

Проверка содержимого показала, что `emma-motion-02.gif` — **однокадровый JPEG 735×588**, а не GIF. Его JPEG-сигнатура начинается с `FF D8`; неправильным оказалось расширение. Старый код уже ссылался на собственный путь этого файла: подмены индексом или фотографией другого слота не установлено. Новый manifest честно отмечает его `animated: false` и сохраняет исходный путь.

Файлы `emma-background.webp`, `emma-gallery-01.webp` и `emma-gallery-02.webp` также содержат JPEG, несмотря на расширение. Настоящие анимации — `emma-motion-01.gif` (27 кадров) и `Emma Watson Kiss GIF.gif` (30 кадров). Различие установлено декодированием существующих файлов, не по их названиям.

### Как заменить или добавить файл

1. Поместите свой файл в `htmlG/assets/`, не изменяя чужие исходники.
2. Укажите его точное имя в `files` нужного ключа. Разрешено одно имя файла, без каталогов, URL, `..`, query или fragment. Пробелы кодируются загрузчиком.
3. Для фотографий используйте `type: 'image'`; для видео — `type: 'video'` или `auto`. Для анимации укажите `animated: true`, для статичного изображения — `false`.
4. Перезагрузите страницу. Первый успешно декодированный кандидат своей записи используется на странице и в просмотре.

Для фоновых и обычных фото предусмотрены JPG, JPEG, PNG и WebP; для движущихся изображений — GIF, анимированный WebP, MP4 и WebM. Для другого basename отредактируйте manifest. `animated` — явная настройка для reduced motion, не автоматическое определение количества кадров. Видео требует поддержки своего кодека браузером; MP4/WebM проверены контролируемыми metadata-событиями, настоящих пользовательских видео в текущем наборе нет. Анимированный WebP также не присутствует в текущем наборе и не проверен реальным воспроизведением.

Точного разрешения не требуется. Изображения сохраняют пропорции; небольшие анимации не растягиваются на большую панель. Полный просмотр использует `contain`. Фон сохраняет пропорции, немного размыт и затемнён отдельным слоем: текст и кнопки не размываются.

Самостоятельной медиагруппы после донатов больше нет. `kiss` ограничена шириной 240 px (при текущем исходнике 300×169 — около 240×135) и является соседним элементом группы контактов, а не отдельной секцией. До 900 px она следует под тремя целыми контактными ссылками без дополнительной фотопанели. `motion2` находится внутри ответа FAQ об Эмме рядом с отдельным локализованным абзацем: ширина фото 216 px, высота около 173 px. До 700 px фото следует под текстом ответа и имеет ширину до 240 px. Оно не растягивается при раскрытии других вопросов, скрывается вместе со своим details и открывается по собственной кнопке. При ошибке медиа текст и ссылки остаются обычным содержимым без зарезервированного фототрека. `gallery2`, `motion1` и `portrait` намеренно не имеют элементов в основном DOM; собственные manifest-записи сохранены для последующего использования. Загрузчик не менялся: он может проверить их локальные кандидаты, но не монтирует их и не подставляет вместо отображаемых файлов.

Загрузка ограничена двумя одновременными проверками и таймаутом 8 секунд на кандидат. Скрытые элементы не блокируют обнаружение файлов. Ошибка скрывает только соответствующее медиа; если файлов нет, страница остаётся читаемой без пустых панелей. Видео приостанавливаются вне видимой области и при скрытии страницы. При `prefers-reduced-motion` подтверждённые анимированные изображения заменяются кнопкой открытия, видео не запускается автоматически. Статичный `motion2` остаётся изображением. Просмотр закрывается кнопкой, Escape или нажатием снаружи и возвращает фокус.

## Логотипы поддержки

Все пути находятся в `htmlG/assets/crypto/`. Логотип отображается пропорционально в области 26×26 px после успешной загрузки. При отсутствии файла название и реквизиты остаются видны; поддельная иконка или случайный PNG вместо него не подставляется.

| Точный путь | Источник, условия и фактический статус |
| --- | --- |
| `htmlG/assets/crypto/ton.svg` | Сохранён неизменённый SVG с [официального сайта TON](https://ton.org/assets/favicon.svg), связанного с [TON Media](https://ton.org/media/). Применяется для идентификации сети; открытая лицензия на все товарные знаки не заявляется. |

Пять поставляемых SVG занимают суммарно 7 120 байт. В них нет скриптов, обработчиков событий, внешних ресурсов и шрифтов. У xRocket PNG встроен локально как data URI. Права на товарные знаки не становятся лицензией исходного кода Gansar; использование не означает одобрение проекта брендами.

Подробные сведения об источниках и ограничениях: `assets/crypto/LICENSING.md`. Размеры, представление, статусы всех семи путей и SHA-256: `assets/crypto/BRAND_ASSETS.json`. Семь ранее добавленных PNG/JPG сохранены побайтно и не используются как недокументированный fallback.

Для полного набора можно самостоятельно добавить **настоящие разрешённые** `ethereum.svg` и `cryptobot.svg` в указанные пути. Страница уже работает без них. `emma-portrait.*` остаётся необязательным; другие фото или видео добавлять не требуется.

## Проверка и границы проверки

Проверены DOM, JavaScript, переводы, точные адреса и ссылки, clipboard success/reject/manual fallback, FAQ, изоляция источников медиа, таймауты, reduced motion и XML логотипов. Контролируемые DOM/video-события не заменяют работу настоящего браузера. Пути декодированы Pillow отдельно от тестов интерфейса. Responsive-проверка выполнена по CSS и метрикам шрифта для заданных ширин; это не снимки реального рендера.

Настоящая визуальная приёмка `file://` остаётся за пользователем: в текущем сеансе действует явный запрет инструмента на открытие файла, который не обходился через другой браузер, localhost или CDP. Реальный системный clipboard, браузерное воспроизведение и точное кадрирование на мониторе также не объявляются проверенными.
